## 🚀 Featured Projects

### 🧬 1. GeneX – AI-Powered Genomic Decision Support System (Graduation Project)
**Category:** AI in Healthcare / Bioinformatics / Full-Stack  

GeneX is an intelligent clinical decision support system designed to assist doctors in **autoimmune disease risk prediction** using **gene expression data**.  
The system integrates machine learning models with a secure, role-based full-stack platform for **patients and doctors**.

- **Tech Stack:** Python, Scikit-learn, Django, Django REST Framework, Flutter, SQL  
- **AI Components:** Feature selection, ML classification models, risk score prediction  
- **Bioinformatics:** Gene expression preprocessing, GEO dataset pipelines, patient file upload handling  
- **System Features:**  
  - Patient gene file upload & prediction  
  - Risk score and ML-based explanation  
  - Secure doctor–patient data sharing (authorization-based)  
  - Doctor notes & medical follow-up  
  - Drug safety & interaction alerts  
- **Focus:** Reliability, security, scalability, explainability, healthcare data privacy  

🔗 **Repository Link:** https://github.com/Hatemmhossam/GeneX
